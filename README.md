## Getting Started

### Prerequisites

- Node.js
- npm or yarn

### Installation

1. Clone the repository

   git clone https://github.com/ha9192631770/travelers.git
   cd travelers


2. Install dependencies

   npm install


3. Run the development server

   npm run dev

   The app will be available at `http://localhost:5174` .
